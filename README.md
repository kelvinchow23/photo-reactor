# Photoreactor Rev B

An update to the [AC-SDL4 photo-reactor](https://github.com/AC-SDL4/photo-reactor)
using custom PCBs for a four-reactor controller and interchangeable LED/fan boards.

The **photoreactor project is Rev B**. Both PCB parts remain **Rev A**:
SDL4-0001 photoreactor-controller and SDL4-0002 photoreactor-led.
